# 🧠 My Practice Method

For every problem I follow this process:

```text
1. Understand the problem
        ↓
2. Identify inputs & outputs
        ↓
3. Break the problem into smaller steps
        ↓
4. Write pseudocode
        ↓
5. Code it myself
        ↓
6. Test normal cases
        ↓
7. Test edge cases
        ↓
8. Debug
        ↓
9. Refactor
        ↓
10. Commit to GitHub
